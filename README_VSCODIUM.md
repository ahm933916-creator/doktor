# تطبيق العيادة الشاملة — حزمة VSCodium

هذه الحزمة تحتوي على ملفات المصدر الكاملة للنسخة الأولية من تطبيق «العيادة الشاملة». المشروع مبني باستخدام Expo Router وReact Native وTypeScript وNativeWind، ويمكن تشغيل واجهته على الويب أو تجهيزها لاحقًا لـ Android.

## المتطلبات

ثبت البرامج التالية قبل التشغيل:

- Node.js إصدار 20 أو أحدث.
- pnpm إصدار 9 أو أحدث.
- VSCodium.
- لتشغيل Android فعليًا: Expo Go على الهاتف، أو Android Studio عند الحاجة إلى محاكي.
- لتفعيل Drizzle والبيانات المشتركة لاحقًا: خادم MySQL مع رابط `DATABASE_URL`.

## التثبيت

افتح مجلد المشروع في VSCodium، ثم افتح الطرفية داخله وشغّل:

```bash
pnpm install
```

إذا لم يكن pnpm مثبتًا، يمكن تثبيته عبر:

```bash
corepack enable
corepack prepare pnpm@9.12.0 --activate
```

## تشغيل واجهة الويب

لتشغيل الواجهة على الويب:

```bash
pnpm dev:metro
```

بعد ظهور رابط Expo افتحه في المتصفح. يمكن أيضًا استخدام:

```bash
pnpm dev
```

وهذا يشغل Metro وخادم API معًا. إذا أردت تشغيلهما في طرفيتين منفصلتين استخدم:

```bash
pnpm dev:metro
pnpm dev:server
```

المنفذ الافتراضي للواجهة هو `8081`، ومنفذ API هو `3000`.

## تشغيل Android

شغّل Metro ثم استخدم Expo Go لمسح QR الظاهر في الطرفية أو في صفحة Expo. من داخل المشروع يمكن استخدام:

```bash
pnpm android
```

يتطلب هذا الأمر إعداد Android Studio أو جهاز Android متصلًا، بينما Expo Go هو الطريق الأسهل للتجربة الأولية.

## قاعدة البيانات

الواجهة الحالية تعرض بيانات محلية/تجريبية حتى تعمل مباشرة بعد تثبيت الحزم. مخطط Drizzle موجود في مجلد `drizzle/` ويشمل المرضى، المواعيد، الفترات المتاحة، الملاحظات، الصور، الفواتير، الدفعات والمصروفات.

لتشغيل أوامر قاعدة البيانات، أنشئ ملف `.env` محليًا ولا تضعه داخل الحزمة أو Git:

```env
DATABASE_URL=mysql://username:password@localhost:3306/clinicsham
```

ثم شغّل:

```bash
pnpm db:push
```

استخدم قاعدة بيانات تجريبية في التطوير. لا تستخدم بيانات مرضى حقيقية قبل إضافة المصادقة والصلاحيات والتخزين الآمن.

## بنية مهمة

- `app/`: شاشات Expo Router.
- `components/clinic-ui.tsx`: مكونات الواجهة المشتركة وهوية التصميم.
- `lib/clinic-data.ts`: بيانات النسخة المحلية التجريبية.
- `drizzle/schema.ts`: مخطط قاعدة البيانات القابل للتوسع.
- `assets/images/`: أيقونات وهوية تطبيق العيادة.
- `plan.md`: خطة التنفيذ والتصميم.
- `TODO.md`: ما تم إنجازه وما تبقى للمرحلة السحابية.
